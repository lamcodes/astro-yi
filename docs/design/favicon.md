## 生成的文件
- `favicon.ico` - 传统网站图标
- `favicon.svg` - SVG 格式图标
- `favicon-16x16.png` - 16x16 像素 PNG
- `favicon-32x32.png` - 32x32 像素 PNG
- `apple-touch-icon.png` - Apple 设备图标
- `android-chrome-192x192.png` - Android Chrome 192x192
- `android-chrome-512x512.png` - Android Chrome 512x512
- `site.webmanifest` - Web 应用清单

## 部署位置
所有图标文件放置在 `public/` 目录下，可通过根路径访问。
