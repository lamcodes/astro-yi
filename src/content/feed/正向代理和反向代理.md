### 反向代理和正向代理中“正/反”怎么理解？

- **正向代理**：代理站在**客户端一边**，帮客户端访问外部 → **“从客户端往外”正向代理**。
- **反向代理**：代理站在**服务端一边**，帮服务端接收外部请求 → **“从外部往里”反向代理**。

可以这么记：

- **正向代理 = 代理客户端**
- **反向代理 = 代理服务端**

不管是正反都是站在代理服务方的角度上。**请求从里到外就是正，请求从外到里就是反**。

```bash
Client  →  Proxy(正向代理)  →  Server

Client  →  Proxy(反向代理)  →  Server

客户端 → 正向代理 → 互联网 → 反向代理 → 后端服务器集群
```
